Language Roulette Admin

Manage languages, UI strings, categories, and questions

GitHub save settings

On GitHub Pages, Save commits content.json into the repo automatically. Create a fine-grained token with Contents: Read and write for this repository. The token stays in your browser only (localStorage) and is never committed.

Languages

Add a language code, then fill UI strings and category labels for it.

UI strings

App chrome translations. Missing values fall back to the default language.

Categories

Wheel labels per language. These update in the app when the language switcher changes.

Questions

Learning prompts stay in German (or your target practice language).

How this works

  1. Enable GitHub Pages for this repo: Settings → Pages → Source = GitHub Actions.
  2. Open the published admin site (usually https://spirea89.github.io/LanguageSpinApple/).
  3. Paste a GitHub token with Contents write access and click Remember settings.
  4. Edit languages/categories, then click Save to GitHub. That commits the JSON files on main.
  5. On your Mac: git pull, then rebuild the iOS app in Xcode.

Local editing still works with python3 admin/dev-server.py. Save will prefer the local server when available.
