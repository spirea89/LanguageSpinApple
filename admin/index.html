Language Roulette Admin

Manage languages, UI strings, categories, and questions

Languages

Add a language code, then fill UI strings and category labels for it.

UI strings

App chrome translations. Missing values fall back to the default language.

Categories

Wheel labels per language. These update in the app when the language switcher changes.

Questions

Learning prompts stay in German (or your target practice language).

How to use with the iOS app

  1. Run python3 admin/dev-server.py (or node admin/dev-server.cjs) from the repo root.
  2. Open http://localhost:5180 and edit content.
  3. Click Save to project (writes content/content.json and the iOS resource copy).
  4. Rebuild the iOS app in Xcode so it picks up the bundled pack.

Without the local server, use Download content.json and replace LanguageRoulette/Resources/content/content.json manually.
